# Haley Harper — Academic & Professional Portfolio

A customized version of the **Dimension** template by HTML5 UP. The original single-page navigation and responsive behavior are preserved; the page content and visual styling have been adapted for an academic and technical portfolio.

## Preview locally

Open `index.html` in a browser. For a local development server, from this directory run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Main files to customize

- `index.html` — name, introduction, navigation, research, projects, about, and contact content.
- `assets/css/main.css` — original template CSS plus a clearly marked portfolio refinement block at the bottom.
- `images/bg.jpg` — full-page background image.
- `images/pic01.jpg`, `pic02.jpg`, `pic03.jpg` — article banner images.
- `images/favicon.svg` — browser tab icon.

The JavaScript in `assets/js/` controls Dimension's animated panels. It has intentionally been retained unchanged.

## Before publishing

1. Verify all personal details and project descriptions.
2. Add a professional email and LinkedIn URL in the Contact section if desired.
3. Add public project/research links and replace the gradient placeholder images with your own figures or photographs.
4. Add a resume PDF only if you want it publicly accessible.
5. Review the attribution in the footer and retain `LICENSE.txt`.

## GitHub Pages

This repository is named `haleylharper.github.io`, which is the expected repository naming pattern for a user site. Put `index.html` at the repository root. In GitHub, open **Settings → Pages** and verify that the site is published from the `main` branch and `/ (root)` (or the repository's existing deployment workflow). The `.nojekyll` file is included because this is a plain static HTML/CSS/JS site.
